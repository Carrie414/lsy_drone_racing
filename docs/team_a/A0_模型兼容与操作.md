## Windows本机复现

在仓库根目录PowerShell执行。这里复用电脑上已有、已验证可用的tests环境，不复制.pixi，也不修改锁文件：

```powershell
$repo = 'C:/Users/Administrator/Documents/Codex/2026-10-21/github-plugin-github-openai-curated-remote/work/carrie-level2-fast-upload'
Set-Location -LiteralPath $repo
$aPython = 'D:/racing-project/lsy_drone_racing/.pixi/envs/tests/python.exe'
$env:SCIPY_ARRAY_API = '1'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:PYTHONPATH = $repo
& $aPython -m pytest tests/team_a/test_policy_adapter.py tests/unit/test_fast_racing.py -q
```

Python环境来自D盘，但PYTHONPATH明确指向本开发仓库；后续使用自己安装的Pixi tests环境时替换解释器路径。
不要在原yiye工作区运行而省略Set-Location/PYTHONPATH，否则可能测试另一个克隆目录。
