## 加载链路

```text
训练侧StagePPOEngine
  → export_npz（base/tuned actor + stage规则 + 来源）
  → NumPy-only NumpyStagePolicy
  → TeamPolicyController
  → 原scripts/sim.py
```

实际运行模块都在control/中，不导入training包、Torch、优化器或critic。原feature编码器不改。
计算与回调保存最终实际指令的逆映射，构造/episode_callback/episode_reset/reset都会清理本实例历史。
正式是否完成由环境判断，step_callback始终返回False。随机Level3、错误接口、错误频率、阶段数不匹配、
错误哈希和synthetic-smoke/unknown权重都会被拒绝。

新NPZ已包含training_kind/update_count字段；旧的合成自检资产不可用于竞速入口。
未来真实候选使用新文件名/新manifest并显式固定新SHA；不能直接覆盖原模型或当前基线资产。

## 你在VS Code的操作

打开当前carrie-level2-fast-upload项目，终端位于根目录。在PowerShell执行：

```powershell
$aPython = 'D:/racing-project/lsy_drone_racing/.pixi/envs/tests/python.exe'
$env:SCIPY_ARRAY_API = '1'
$env:PYTHONDONTWRITEBYTECODE = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:OMP_NUM_THREADS = '1'
$env:PYTHONPATH = (Get-Location).Path
& $aPython -m pytest tests/team_a tests/unit/test_fast_racing.py -q
```

预期49 passed；这是代码检查耗时，不是圈速。然后查看模拟场景：

```powershell
& $aPython scripts/sim.py --config=level2.toml --controller=team_policy_controller.py --render=True --n_runs=3
```

前几秒可能进行JAX初始化；需要时Ctrl+C停止。Flight time是该回合模拟时间，Finished是是否完成，
Gates passed是穿越次数；当前四个物理门按序列需要五次正确穿越。失败回合的终止时间不能当作成功圈速。

无界面诊断（非训练、非最终评测）：

```powershell
& $aPython -m training.team_a.check_deployment
```

首次自检曾遇到Windows共用pytest临时目录权限问题，助手已用独立workspace临时目录重跑通过。
你自己的终端若也出现pytest-current访问拒绝，可指定一个全新测试目录，不修改权限或删除其他临时目录：

```powershell
$teamTestTemp = Join-Path $env:TEMP ('team-a-tests-' + [guid]::NewGuid().ToString('N'))
& $aPython -m pytest tests/team_a tests/unit/test_fast_racing.py -q --basetemp $teamTestTemp
```
